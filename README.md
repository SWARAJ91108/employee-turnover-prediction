# Employee Turnover Prediction

Machine Learning project to predict employee turnover using:

- Logistic Regression
- L1 (Lasso) Regularization
- L2 (Ridge) Regularization

## Features
- Job Satisfaction
- Performance Rating
- Years At Company
- Work Life Balance
- Monthly Income
- Age
- Annual Bonus
- Training Hours

## Target
Employee Turnover
0 = Stay
1 = Leave

## Results
L1 (Lasso): 86.67%
L2 (Ridge): 85.93%

## Tools Used
Python, Pandas, Scikit-Learn
